# Journal

## Phase 1
In this phase, I created a simple vault system that checks if the correct key is entered. I tested it with different values to make sure it worked. Using "use strict", helps catch coding mistakes early and make debugging easier.
<br>
## Phase 2
In this phase, I added custom errors to handle incorrect or missing keys. Returning a value just gives a result, while throwing an error lets the program know something went wrong. Custom errors are helpful because they make it easier to understand what caused the problem.
<br>
## Phase 3
I added try, catch, and finally to handle errors without stopping the program. The catch block only runs when an error happens, but finally runs everytime. This is useful when a program need to close a file or clean up resources, even if something goes wrong.
